# ARM's wiki (copy)

These pages are the [ARM wiki](https://github.com/automatic-ripping-machine/automatic-ripping-machine/wiki) as it
was when A2RM forked from ARM 2.24.4. They are kept unchanged because they're still the best guide to the parts A2RM
doesn't change (drives, Docker volumes, permissions, MakeMKV keys, ARM's own settings).

They describe ARM, not A2RM: the install scripts and Docker Hub image they mention install plain ARM. For A2RM, see
the [README](../README.md) and [ARM and A2RM: what's different](../docs/ARM-vs-A2RM.md).
