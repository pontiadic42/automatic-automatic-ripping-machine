# Contributing

A2RM is a personal fork of the [Automatic Ripping Machine (ARM)](https://github.com/automatic-ripping-machine/automatic-ripping-machine)
and isn't set up for outside contributions: there's no issue tracker. You're welcome to fork it.

If you've found a bug that is in ARM itself (it happens with plain ARM too), report it to ARM following
[ARM's contribution guide](https://github.com/automatic-ripping-machine/automatic-ripping-machine/wiki/Contribute).
Please don't report A2RM problems to ARM.

For working on the code: the tests and how to run them are in the [README](README.md#tests). A2RM's own code is in
`arm/automation/` (the logic) and `arm/ui/automation/` (its pages); keep changes to ARM's files small so they're easy to
compare with ARM.
